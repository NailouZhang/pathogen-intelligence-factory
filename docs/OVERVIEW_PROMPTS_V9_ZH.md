# v9 文献与新闻汇总提示词策略

## 文献汇总

输入 15～25 篇，字段完整包含作者、期刊、日期、类型、摘要、中文摘要、七/五要素和关键数字。模型以科研新闻编辑身份，按主题聚合，而不是逐篇复述。输出：标题、导语、3～6条核心进展、研究趋势、证据提醒和引用 ID。

强约束：中文字段只能使用中文；不能出现 `...` 或 `……`；不能截断句子；不能把综述写成新实验；定量结果必须保留原数值；每个重点结论引用真实 paper_id。

## 新闻汇总

输入 15～25 条具有 `full`、`partial` 或 `syndicated_summary` 证据的新闻。模型以公共卫生机构新闻编辑身份合并同一事件，区分已确认、疑似、媒体转述和未解决信息。输出：标题、总体情况、已确认动态、风险与影响、应对措施、待确认事项和引用 ID。

程序校验失败时不发布不合格 LLM 文本，而使用中文单篇分析和中文摘要构造完整句回退。
