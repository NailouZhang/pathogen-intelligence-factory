# v10 文献要素去重与截断修复

## 要素边界

研究七要素和综述五要素在提示词中声明“允许证据角色”和“禁止内容”。例如方法字段只能回答做了什么实验、检测、统计或计算；不能重复背景、研究对象或结果。设计字段只回答设计类型、地点、时间、样本和对照，不能复述技术步骤。

## 输出后处理

1. 完整句检测：省略号和已知损坏尾句不会发布；
2. 字段内去重：同一字段重复句合并；
3. 跨字段去重：RapidFuzz 字符与 token-set 相似度检测完全相同或高度近似句；
4. 修辞角色补位：被删除后为空的字段只能从其匹配角色证据选择新句；
5. 证据 ID 检查：引用必须存在于当前文章证据包；
6. 数字一致性：样本量、百分比、P 值、置信区间和单位不得凭空变化；
7. 完整结束：字段不得以逗号、分号、冒号或省略号结尾。

无法从原文支持某项时，使用该字段专属的“原始证据未报告”说明，不把其他字段内容复制进来。
