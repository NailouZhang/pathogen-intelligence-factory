# v7 相关性复核、去重、筛选与排序

## 1. Python 覆盖全部候选

Python 在标题、数据库摘要和检索来源上执行：

- 完整病毒身份命中；
- 白名单成员命中；
- 特异疾病命中；
- 限定缩写及其必要上下文；
- 普通上下文命中；
- 排除实体；
- 身份出现频次；
- 命中的核心检索概念数量；
- 命中的独立数据来源数量。

明确相关记录直接保留，明确无关记录直接拒绝，边界记录进入 Gemini/Groq 紧凑复核。

## 2. LLM 只处理边界记录

日常 `balanced` 模式：

- Python 处理 100% 候选；
- 只把 `review` 或元数据不足、但由核心查询命中的记录交给 LLM；
- 提示词每批只发送一次主题边界；
- 每条记录只发送标题、检索概念、身份命中、上下文、排除词和相关句子；
- 按 Token 预算动态分批直到队列为空；
- 模型只输出 A/C/B/N/U 短代码；
- U 类才升级到更完整句子证据；
- Gemini/Groq 均失败时使用 Python 确定性回退。

`all_compact` 仅用于手工全面审计，不作为日常默认。

## 3. 文献去重

优先级：

1. DOI；
2. PMID/PMCID；
3. 规范化标题 + 第一作者；
4. 标题 token-set 相似度、作者和年份；
5. 预印本与正式发表版本关系。

合并时保留所有来源、完整作者、发布日期、开放获取链接、检索概念、引用数和较长摘要。

## 4. 新闻去重

- 规范化 canonical URL；
- 去除常见跟踪参数；
- 标题 token-set 相似度；
- 日期一致性；
- 合并转载来源和较长摘要；
- 重复来源数量作为热点和可信度信号。

## 5. Top-50 排序

文献评分考虑：

- 病毒相关性；
- PubMed/Europe PMC 等来源权重；
- 多提供者收敛；
- 多核心概念命中；
- 系统综述、Meta 分析、随机试验、队列、指南等研究设计；
- API 已有摘要；
- DOI、开放获取和引用数；
- 7 天窗口内的新近性；
- outbreak、surveillance、vaccine、treatment、variant、genomic 等热点信号。

新闻评分考虑：

- 病毒相关性；
- WHO、CDC、政府卫生部门等官方性；
- 大学、医院、研究机构可信度；
- 多来源转载或印证；
- 核心概念覆盖；
- 疫情、传播、疫苗、治疗、基因组热点；
- 时间新近性。

先分 A/B/C，再按质量分、日期和标题确定性排序。不是随机抽样。
