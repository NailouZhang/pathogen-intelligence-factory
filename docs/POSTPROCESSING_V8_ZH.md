# v8 后期文献与新闻处理规范

## 1. 汇总样本

文献和新闻分别选择 15～25 条。当合格记录不足 15 条时，使用全部合格记录，并在汇总中说明证据数量有限；绝不引入被拒绝记录凑数。

## 2. 文献综合汇总

输入字段：作者、期刊、日期、标题、英文摘要、中文摘要、文章类型、A/B/C 等级、证据等级、七/五要素和关键数字。模型不得逐篇按顺序复述，必须聚合相近研究、识别共识与冲突、突出最重要的定量结果，并列出来源 paper_id。

## 3. 新闻综合汇总

仅使用正文状态为 `full` 或 `partial` 的记录。重复事件先合并；官方来源优先；病例、死亡、暴露、时间和地点不能跨事件相加；输出区分确认、疑似、调查中和一般指导。

## 4. 单篇分析

原始研究七要素全部必填；综述五要素全部必填；新闻五要素全部必填。每个字段必须引用输入证据 ID，不能引用不存在的编号。

## 5. 翻译门禁

翻译提供方全部失败时，LLM 作为最终免费兜底。仍失败的记录从展示中移除，不能发布错误占位符。数字、百分比、P 值、置信区间和单位必须保持。

## 6. 微信新闻长度

新闻正文可很长，但单篇 LLM 先生成 55～170 词 body-grounded 英文简报，再翻译并按五要素压缩。`wechat_summary_zh` 最长 500 个中文字符；页面仍可保留更完整的英文正文来源信息。

## 7. 补位

最多 20 条补位候选用于填补内容获取失败，最终仍只展示最多 50 篇文献和 50 条新闻。补位不会扩大到全部候选抓正文。
