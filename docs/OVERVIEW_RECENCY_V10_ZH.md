# v10 文献汇总与时效排序

## 统计概览

页面在文献和新闻汇总前单独显示两行醒目统计：原始记录、时间窗内记录、候选筛选、删除重复、相关性通过、最终纳入，以及研究/综述构成。

## 15～25篇文献选择

优先级依次为：

1. 发表日期位于本期报告窗口；
2. A/B/C 优先级和质量分；
3. E2/E1/E0 证据等级；
4. 多数据库来源收敛；
5. 多核心概念命中；
6. 系统综述、Meta 分析和重要原始研究；
7. 期刊和研究方向多样性。

旧文献或日期不明记录只在本周合格文献不足 15 篇时补位。汇总模型必须以科学新闻编辑身份按主题合并研究，保留最重要数字和来源 ID，不得按输入顺序逐篇复述。

## 发布门禁

中文汇总必须为完整中文句，不含省略号、翻译占位符、模型内部过程话语或不存在的来源 ID。失败时使用确定性中文编辑回退，而不是发布中间推理语句。
