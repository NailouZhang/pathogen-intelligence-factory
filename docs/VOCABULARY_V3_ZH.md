# 专业词库 v3：固定来源、确定性编译、二次相关性闸门

## 为什么废弃搜索发现

Google CSE 或通用搜索引擎返回的是排名结果，不是稳定的数据合约。相同关键词可能在不同时间返回搜索页、分类页、旧版页面或无关近邻病毒页面，导致词库漂移。v3 不再搜索 ICTV/ViralZone 页面，而是由人工在每个 `seed.yaml` 中维护固定权威 URL。

## seed.yaml 的职责

每个 profile 明确保存：

- 主题实体层级；
- 纳入与排除边界；
- 允许成员白名单；
- 安全身份锚点候选；
- 需要限定的缩写；
- 疾病身份候选；
- 只能使用 AND 的上下文词；
- 禁止单独检索词；
- 低风险 NOT 候选；
- 固定权威网页；
- 人工查询骨架，仅作审计参考。

## 构建流程

1. 只抓取 `authoritative_sources` 中的 URL；
2. 清理网页样板并缓存正文和 SHA-256；
3. 将人工边界、候选词和权威正文交给 Gemini，失败时交给 Groq；
4. 模型不得搜索网页、调用记忆补全或扩大白名单；
5. 模型输出七层术语结构；
6. Python 保留人工边界并过滤模型扩展；
7. Python 重新编译数据库专用查询；
8. 执行分支锚点、缩写、范围、查询长度和过度排除检查；
9. 检索结果再次经过文章级相关性评分；
10. 高精度生产模式只保留 `accept`，`review` 留在审计数据中但不展示。

## 七层术语

- `identity_anchor_terms`
- `qualified_identity_terms`
- `member_identity_terms`
- `disease_identity_terms`
- `context_terms`
- `display_only_terms`
- `exclusion_terms`

`display_only_terms` 优先级最高：某词即使同时出现在候选身份栏，只要被标记为禁止单独使用，编译器就会将其降级，不让它成为独立 OR 分支。

## 文章级评分

- 标题完整身份：+6
- 标题白名单成员：+5
- 标题特异疾病：+4
- 摘要完整身份：+3
- 摘要白名单成员：+2
- 上下文：+1
- 排除实体主导标题且无目标标题锚点：-6
- 未限定缩写：-4
- 只有上下文：-4

`score >= 6` 且确有身份锚点才进入展示与公众号。
