# v9 偏差修复说明

## 1. 文献数量从 50 降为 35

v8 在翻译前已经截取 50 条，翻译门禁删除失败的 15 条后没有从补位候选补回。v9 保留 80 条展示候选到分析和翻译结束，只在 `translation_ready` 确认后最终选择 Top 50。只要就绪池不少于 50，网页就保持 50 条。

## 2. 有效新闻为 0

v8 的新闻正文解析对聚合器跳转覆盖不足，34 条已通过相关性审查的新闻全部在正文门禁被删除。v9：

- RSS 解析保存所有 entry links 和 summary 中的外链；
- 去重合并时优先 GDELT/原始站直接 URL；
- 解析 canonical、OpenGraph、JSON-LD、mainEntityOfPage、脚本内链接和外部锚点；
- 高精度/高召回/正文选择器/可见段落多路径提取；
- 通过严格质量门禁的实质性转载摘要可降级保留；
- 标题重复、导航、Cookie、版权文本仍拒绝。

## 3. 中文文献汇总出现英文和省略号

v9 分离文献与新闻提示词，并增加程序级中文比例、完整句、无省略号、无占位符、来源 ID 和长度校验。确定性回退只读取中文标题、中文摘要和中文要素。

## 4. 七要素内容混杂

v9 对摘要句进行背景、目标、设计对象、方法、结果、解释、结论、局限和意义角色识别。提示词为每个输出字段给出允许与禁止的证据角色，验证器拒绝方法证据填入背景、背景证据填入结果等错配。

## 5. 封面仍写每日情报

封面样式版本、页面标题、微信标题和 RSS 标题统一升级为“每周情报”，样式版本变化会触发新封面生成。
