# v8 文献与新闻综合汇总策略

## 文献汇总

选择 15～25 篇，优先 A 级、完整摘要、较强研究设计、重要数字结果和多来源收敛记录。输入包括：

```text
paper_id、标题、中文标题、作者、期刊、发表日期、文章类型、等级、质量分、英文摘要、结构化分析、关键数字、证据等级
```

输出：中文标题、中文导语、3～6 条核心发现、趋势/意义、证据提醒、英文标题、英文综合简报和来源 paper_id。

## 新闻汇总

选择 15～25 条正文验证成功的新闻。输入包括：

```text
news_id、标题、发布机构、发布日期、来源类别、正文精炼、五要素、等级和正文状态
```

输出：中文官方式标题、导语、3～6 条合并事件、风险与应对、核验限制、英文标题、英文简报和来源 news_id。

## 质量门禁

- 不得把文献和新闻混合。
- 不得把综述写成新实验。
- 不得使用标题推断新闻事件。
- 不得写入翻译错误占位符。
- 结论必须能回溯到输入 ID。
- 汇总失败时使用分离式确定性兜底，不能回退到混合概述。
