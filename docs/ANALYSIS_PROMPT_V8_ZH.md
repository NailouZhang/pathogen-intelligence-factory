# v8 强约束单篇分析策略

## 原始研究七要素

1. 研究问题与背景。
2. 研究设计与研究对象。
3. 核心方法。
4. 主要结果。
5. 作者解释与创新点。
6. 科研与公共卫生意义。
7. 局限与证据强度。

## 综述五要素

1. 综述范围与核心问题。
2. 证据基础与综述方法。
3. 当前共识与最重要结论。
4. 争议、异质性与证据缺口。
5. 科研、监测与实践启示。

## 新闻五要素

1. 时间。
2. 地点与涉及对象。
3. 核心事件与确认状态。
4. 规模、影响与风险。
5. 官方应对、当前状态与不确定性。

## 弱模型稳定约束

- 一次只输入一条记录。
- 证据句使用 A1/A2 或 N1/N2 编号。
- 固定 JSON Schema。
- 每个字段必须非空并引用存在的证据 ID。
- 缺失信息固定写 `Not reported in the supplied evidence.`。
- 数字必须与原文集合一致。
- 研究类型不能被改变。
- 验证失败不能直接进入页面；程序重试或使用确定性框架填充。
- 缓存键包含原文哈希和提示词策略版本，提示词升级后不会误用旧分析。
