# v6 全候选复核

## 不再存在固定篇数和摘要前缀限制

v5 的文献/新闻 LLM 复核篇数和固定字符前缀限制已经废弃。v6 先由 Python 检查 100% 候选，再为全部候选构建紧凑证据包，按 Token 预算动态分批，循环处理到队列为空。

## 紧凑证据包

包含标题、检索锚点、来源通道、完整身份命中、限定缩写、上下文、排除命中和完整证据句。不会机械截取摘要开头。

## 两轮复核

第一轮输出 A/C/B/N/U。只有 U 类进入第二轮，使用完整摘要或由开头、身份句、关键上下文句和结论句构成的证据。

## 无模型时

Gemini 和 Groq 均不可用或单批失败时，系统执行 Python 全候选确定性回退，并在审计中标记方法，不把失败记录伪装为已由 LLM 审查。

## 深度分析范围

翻译、五要素和总览只处理最终质量排序后的文献 Top 50 与新闻 Top 50。
