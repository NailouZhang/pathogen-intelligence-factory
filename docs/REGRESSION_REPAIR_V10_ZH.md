# weekly21 v10 后处理偏差修复

本次日志说明检索并非瓶颈：2608 条文献记录经筛选和去重后仍有 227 条通过相关性复核，新闻也有 34 条通过；问题集中在新闻正文全部失败以及翻译/后处理门禁后的数量和呈现。v10 不重新扩大查询词，而是修复时效选择、统计呈现、模型中间句过滤、要素排他性和新闻正文恢复。

## 验收

- 统计概览作为文献/新闻汇总前的单独醒目行；
- 文献汇总的 15～25 条输入优先来自本周发表记录；
- 最终中文区域没有内部保留句、省略号和翻译占位符；
- 七要素/五要素不存在高相似跨字段句；
- 新闻审计能显示静态与浏览器每次尝试；
- 正文失败可使用合格的实质来源摘要，但标题重复不能入选；
- 微信新闻摘要不超过 500 中文字符。
