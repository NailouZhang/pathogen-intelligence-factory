# v9 单篇精读与要素对齐

每篇文献独立输入，证据按句编号并标记修辞角色。研究七要素、综述五要素和新闻五要素均有固定 JSON schema、必填字段、最短信息量、数字一致性和 evidence_id 约束。

研究论文字段边界：

- 背景问题：只允许研究背景、知识缺口和目标；禁止样本流程、检测步骤和结果数字。
- 设计对象：研究类型、地区、时间、样本、人群、对照和随访；禁止把检测步骤作为主要内容。
- 方法：实验、检测、测序、统计、暴露和结局定义；禁止意义评价。
- 结果：只保留实际结果、效应量、比例、P值、区间和阴性结果；禁止方法描述。
- 解释创新：作者解释、与既往证据关系和新意；不能把模型推测写成作者结论。
- 意义：对监测、诊断、治疗、疫苗、生态和政策的可支持影响。
- 局限：设计、样本、偏倚、外推和仅摘要证据。

校验不通过时，自动换模型；仍失败则使用角色对齐的 Python 证据提取，不再按摘要句序机械填入字段。
